# Archived benchmarks

This directory contains selected benchmark results that are useful as project
evidence and must remain recoverable through Git. Before committing a result,
review it for credentials, private hostnames, user names, and machine-specific
paths.

Routine or disposable runs belong in the repository-root
`benchmark-results/` directory instead. That directory is intentionally ignored
by Git and therefore requires a separate backup if it must survive loss of the
local machine.
